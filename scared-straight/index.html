新着アラート

GitHub Actions が毎朝 7:00（JST）に Google ニュース RSS と自治体サイトを巡回し、募集・入札・実施情報を収集します。案件性のあるものは公告ページ本文まで読みに行き、提出期限を自動で抽出します。締切14日以内は色が変わり、7日以内は点滅します。
「選定結果」「受付終了」などの終了案件と、締切を過ぎたものは既定で非表示です（チップで表示できます）。実施ニュースは「その自治体に予算が付いている」証拠なので、翌年度の提案先リードとして扱ってください。

東京都マーケット

東京都都民安全総合対策本部が毎年8月に公表する「区市町村における交通安全対策事業の現況」には、［19表］としてスタントマンを活用した交通安全教室の実施状況が区市町村別に載っています。令和8年3月31日現在版（2026年8月26日公開・112ページ）から、全区市町村の予算額・実施回数・担当課・電話番号を抽出しました。これは推計ではなく、東京都が公表している実数です。前年版との差分も列として持たせています。

令和8年度予算の内訳

予算は毎年、実績を2割上回ります。 令和7年度は 77,542千円の予算に対し実績 61,954千円で、執行率は79.9%。予定していた249回のうち実施は214回でした。実績ベースで見ると令和6年度61,909千円→令和7年度61,954千円とほぼ横ばいで、市場は拡大していません。「予算は付いているのに使われていない2割」が、提案次第で取りにいける余地です。年度後半に残予算を消化したい担当課は実在します。
2026年4月、自転車に青切符（交通反則通告制度）が導入されました。 16歳以上が対象で、ながら運転・信号無視など113種類の違反に5,000〜12,000円の反則金がかかります。高校生が直接の処罰対象になったため、高校向けの安全教育ニーズは構造的に上がります。同じ令和8年4月には第12次東京都交通安全計画も策定されました。予算が横ばいでも、この2つを根拠にすれば予算要求の材料を担当課に渡せます。

価格を読むときの前提

  • 単価は「1回あたり」で契約されることが多い。年間◯校の巡回契約でも単価×回数の積算になるため、1回単価が営業上の基準値。
  • スタント人数（4〜6名が一般的）、車両手配、警備・保険、会場設営、事前打合せ、雨天順延条項が金額差の主因。
  • 県費案件は「県内◯校を年間で巡回」となり、総額が数百万円規模になる（1回単価は据え置き）。
  • 政令市は「年間包括」で出すことがある。千葉市の「交通安全教室等業務委託」は令和8年度 10,260,800円（税込）の年間契約で、落札は一般財団法人千葉市交通安全協会。スケアード単体ではなく年間の教室運営ごと取る形で、元請けが協会になるため、実演部分は再委託で入ることになる。
  • 東京都の公表値では1回あたり237〜390千円に収まる自治体が大半。国立市539千円のように年1回だけの自治体は単価が高く出る（車両手配や設営の固定費が1回に集中するため）。
  • 予定価格は非公表が多いが、前年度の落札額が実質的な上限として機能する。

相場データを自分で積み上げる手順

  • ① 発注実績DBの機関名 ＋「入札結果」「契約結果の公表」「随意契約結果」でサイト内検索する。ほぼ全自治体が年度別に結果一覧を公開している。
  • ② 一覧のCSV/PDFを「スケアード」「自転車」「交通安全教室」で全文検索し、件名・落札者・落札額を転記する。
  • ③ 130万円（自治体により100万〜160万円）を超える委託は入札、それ以下は見積合わせ・随意契約になる。少額随契の枠に入る規模なら、公告を待たずに直接営業した方が速い。
  • ④ NJSS等の有料サービスを使う場合は「スケアード」「事故再現」「自転車安全教室」の3語で落札履歴を横断検索すると、単価のレンジが一気に埋まる。

  • .github/workflows/scared-straight-alert.yml … 毎朝 7:00 JST に自動実行し、差分があればコミット。
