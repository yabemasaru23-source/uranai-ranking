# スケアードストレート案件リサーチ・アラート

スケアードストレート（スタントマンによる交通事故再現型の交通安全教室）について、
**全国の自治体・教育委員会・警察が出す募集／入札／実施情報を毎日自動収集し、
発注実績・価格相場・営業カレンダーとあわせて一覧化する**営業支援サイトです。

## 公開URL

GitHub Pages を有効にしている場合：

```
https://<ユーザー名>.github.io/uranai-ranking/scared-straight/
```

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | サイト本体。1ファイル完結（外部依存なし）。調査データを内蔵し、`leads.json` があれば自動で最新データに差し替える |
| `fetch_leads.py` | 案件クローラー。Google ニュース RSS ＋ 自治体サイトを巡回し `leads.json` を生成・追記する |
| `sources.json` | 巡回先の設定。監視したい自治体の入札公告ページURLを足すだけで対象が増える |
| `leads.json` | クローラーの出力（自動生成・自動コミット） |
| `../.github/workflows/scared-straight-alert.yml` | 毎朝 7:00 JST に自動実行するワークフロー |

## 手元で実行する

```bash
pip install requests beautifulsoup4 lxml
python scared-straight/fetch_leads.py
```

`leads.json` が更新されます。ローカルで表示を確認するときは、`fetch()` が
`file://` では動かないため簡易サーバー経由で開いてください。

```bash
python -m http.server 8000
# → http://localhost:8000/scared-straight/
```

## 監視対象を増やす

`sources.json` を編集します。

- `google_news_queries` … ニュース検索のクエリ。地域名を足すと地元案件を拾いやすくなる
- `scan_pages` … 巡回する自治体ページ。`org` / `label` / `url` の3つを書くだけ

追加した翌朝の実行から反映されます。

## 新着（NEW）の判定

初回に検知した日付（`first_seen`）を `leads.json` に保存し続けるため、
2日目以降は**その日はじめて見つかったものだけ**が NEW になります。
一度検知した案件は最大400日保持します。

## 案件度スコア

タイトルと機関名から0〜100で採点しています。

| 要素 | 加点 |
| --- | --- |
| 「スケアード」を含む | +50 |
| 「スタント」「事故再現」を含む | +15 |
| 「自転車」「交通安全教室」等を含む | +10 |
| 「入札」「公告」「業務委託」「公募」「プロポーザル」を含む | +25 |
| 「募集」「契約」等を含む | +12 |

## 注意

- 掲載している金額・所管課・調達方式は調査時点（2026年8月）の公開情報です。年度で変わります。
- アプローチ前に必ず出典リンクから一次情報を確認してください。
- クローラーは公開RSSと公開ページのみを取得し、認証の必要なサイトへはアクセスしません。
